## Product direction

Core hook: the game changes its rules during a run and remembers the player's choices.

Retention systems planned:
- adaptive events
- daily objectives
- persistent collection
- streaks
- global events
- cosmetic progression

Monetization planned:
- rewarded video at natural breakpoints
- optional cosmetic purchases
- no pay-to-win
- analytics for start, event choice, game over, return session and rewarded completion

The first prototype deliberately uses no real advertising or purchases.
